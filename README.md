## 核心玩法

### 战斗（即时制，非回合）
- 自动锁定最近的僵尸开火，手指左右拖动可移动炮台
- 僵尸成波次从上方推进，撞到底部防线会持续扣血，**防线生命归零即失败**
- 击杀掉落经验宝石（绿）和金币（黄），自动吸附拾取
- 经验满升级 → **三选一**选技能（可免费刷新）
- 能量条蓄满后点击右侧技能图标释放主动技能
- 局内金币可建造炮台（寒冰/火焰/电磁/狙击）
- 每 10 关出现 BOSS

## 技术说明

- **纯前端**：原生 HTML/CSS/JS，无构建步骤
- **战斗渲染**：Canvas 2D
- **数据存储**：GitHub 仓库（每 30 秒自动保存 + 关键操作立即保存）
  - 玩家存档：`data/zb/players/{uid}.json`
  - 排行榜：`data/zb/leaderboard.json`
- **离线可用**：断网时存档进本地队列，联网自动补传

## GitHub 连不上怎么办

国内访问 `api.github.com` 经常超时，游戏底部/后台会显示「离线」。解决方法：

1. 注册 https://dash.cloudflare.com（邮箱即可，不用域名不用绑卡）
2. Workers & Pages → Create → Create Worker
3. 名字填 `xx-proxy` → Deploy
4. Edit code，代码全删，粘贴后台「系统设置」里给的完整代码 → Save and Deploy
5. 复制顶部 `https://xx-proxy.你的账号.workers.dev`
6. 填入游戏「设置 → 网络 → 自定义加速地址」或后台「系统设置」，保存

另外推荐把仓库也接到 **Cloudflare Pages**（Connect to Git 选 `xiuxian-game`，输出目录 `/`），国内比 `github.io` 稳定，且共用同一份数据。
