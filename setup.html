⚙️ 一键配置向导

填好下面几项 → 自动生成配置 → 粘回仓库的 js/api.js

第 1 步 · 填你的信息

两个都填 main 就行。玩家多了想分开，看教程「进阶」一节。
做完教程第 8 步（自建 Cloudflare 代理）后再回来填。填了能大幅解决连不上的问题。

第 2 步 · 生成结果

点上面的「生成配置」按钮…

第 3 步 · 粘回仓库

1. 打开你的仓库，进入 js 文件夹，点开 api.js
2. 点右上角铅笔 ✏️ 进入编辑
3. 找到文件最开头这段（大约前 25 行）：
const GH = { ... };
4. 整段删除，粘贴上面「生成结果」里的全部内容
5. 点绿色 Commit changes

💡 更简单：点「⬇️ 下载完整 api.js」，把下载的文件直接拖进仓库的 js/ 目录覆盖原文件。

第 4 步 · 验证

打开游戏 → 注册一个道号 → 进游戏后看底部状态栏：
● 绿点「云端已连接」 = 成功，去仓库 data/players/ 应该能看到新生成的 .json 文件
● 红点「离线模式」 = 网络不通，去做教程第 8 步（自建代理）
